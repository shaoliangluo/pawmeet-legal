PawMeet 隐私政策

更新日期：2026年7月28日 · 生效日期：2026年7月28日

PawMeet（以下简称「本应用」或「我们」）由 PawMeet 运营方（以下简称「运营方」）提供。我们深知个人信息对您的重要性，将按照法律法规要求，采取相应安全保护措施，保护您的个人信息安全可控。请您在使用前仔细阅读本政策。

一、我们收集的信息

为实现功能所必需，我们可能收集以下信息（具体以您使用的功能及授权为准）：

  • 账号信息：手机号、密码（加密存储）、昵称、头像、PawMeet UID、注册时间等；
  • 第三方登录信息：在您授权前提下，从华为账号、微信等获取的 OpenID、UnionID、昵称、头像等；
  • 资料与内容：您填写的城市、发布的活动/需求/动态、评论、私信及上传的图片、视频；
  • 位置信息：在您授权后，用于地图选点、附近活动、城市展示等（可拒绝或关闭系统定位权限，部分功能将不可用）；
  • 设备与日志：设备型号、系统版本、应用版本、操作日志、崩溃信息、网络状态，用于安全风控与服务改进；
  • 交易信息：会员订单号、支付状态、权益使用情况（支付密码由第三方支付机构处理，我们不收集完整支付密码）。

二、信息的使用目的

  • 注册登录、身份验证、密码找回与账号安全；
  • 展示个人资料、实现活动报名、社区互动、私信与通知；
  • 会员权益发放、订单处理、退款与客服；
  • 反欺诈、反垃圾、违规内容处置及履行法定义务；
  • 统计分析、产品优化（尽量采用去标识化方式）。

三、信息的共享与披露

我们不会出售您的个人信息。仅在以下情形共享或披露：

  • 经您明确同意；
  • 为完成支付、登录、推送、地图、云存储等服务，向关联第三方提供必要信息（见下文「第三方 SDK」）；
  • 为遵守法律法规、诉讼、政府主管部门强制性要求；
  • 为保护您、我们或其他用户的生命、财产等重大合法权益所必需。

四、存储与保护

  1. 您的数据主要存储在中华人民共和国境内（uniCloud 等云服务）。
  2. 我们采用访问控制、传输加密、权限最小化等措施保护数据安全，但互联网环境无法保证绝对安全。
  3. 账号注销或法定保存期限届满后，我们将删除或匿名化处理您的个人信息，法律法规另有规定的除外。

五、您的权利

您可通过应用内「账号设置」查询、更正昵称、头像、手机号等资料；可通过修改密码、UID 重置密码管理账号安全。您有权撤回定位、相册、相机等系统权限（在设备设置中操作）。如需访问、复制、删除个人信息或注销账号，请通过应用内反馈或本政策末尾联系方式向我们提出申请，我们将在法律规定期限内处理。

六、未成年人保护

本应用主要面向成年人。若您为未满十四周岁的未成年人，请在监护人陪同下阅读本政策，并在监护人同意后使用。我们不会主动面向未成年人推广付费服务。

七、第三方 SDK 与服务

为实现相关功能，本应用接入了以下第三方 SDK / 服务。我们仅在实现功能所必需的范围内共享信息；第三方将按其自身隐私政策处理相关信息。您亦可在全国 SDK 管理服务平台（https://sdk.caict.ac.cn/official/#/home）查询相关登记信息。

1. APP支付客户端SDK

  • SDK 名称：APP支付客户端SDK
  • 开发者：支付宝(杭州)信息技术有限公司
  • 收集信息范围：设备标识信息、网络信息、订单与交易相关信息等（以支付宝实际收集范围为限）
  • 使用目的：帮助用户完成 App 内订单支付
  • SDK 隐私政策链接：https://opendocs.alipay.com/open/54/01g6qm#支付宝 App 支付客户端 SDK 隐私政策

2. 消息推送 SDK Android

  • SDK 名称：消息推送 SDK Android
  • 开发者：每日互动股份有限公司
  • 收集信息范围：设备标识信息（含 OAID 等）、网络信息、推送相关日志与应用列表等（以个推实际收集范围为限）
  • 使用目的：向用户推送通知消息（如互动提醒、系统通知等）
  • SDK 隐私政策链接：https://docs.getui.com/privacy/

3. 移动智能终端补充设备标识体系统一调用SDK

  • SDK 名称：移动智能终端补充设备标识体系统一调用SDK
  • 开发者：中国信息通信研究院
  • 收集信息范围：设备相关标识信息（OAID 等，以设备与系统实际可读取范围为限）
  • 使用目的：提供统一的补充设备标识（OAID）调用能力，用于统计分析、消息推送、账号与设备安全风控等
  • SDK 隐私政策链接：https://www.msa-alliance.cn/col.jsp?id=122

4. 其他可能接入的服务

  • DCloud/uni-app 基础框架与 uniCloud 云服务（可能涉及设备唯一识别码等，详见上文及 DCloud 相关隐私政策）；
  • 微信开放平台（小程序登录、支付等，以实际开通为准）；
  • 华为账号服务、华为支付（鸿蒙端）；
  • 阿里云内容安全（文本与图片审核，服务端调用）。

上述第三方将按其自身隐私政策处理相关信息，建议您同时阅读第三方条款。

八、政策更新

我们可能适时修订本政策，并通过应用内提示、公告等方式通知。重大变更将再次征求您的同意（如法律法规要求）。更新后继续使用即表示您接受修订后的政策。

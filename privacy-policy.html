一、我们如何收集和使用您的个人信息

我们收集信息的主要途径包括：您主动提交的信息、您使用服务时我们直接获取的信息，以及经您授权后从合法第三方获取的信息。我们仅基于本政策声明的目的处理您的个人信息。因版本与功能配置差异，实际收集范围以您使用时的情况为准。

我们收集的信息（概览）

为实现功能所必需，我们可能收集以下信息（具体以您使用的功能及授权为准）：

  • 账号信息：手机号、密码（加密存储）、昵称、头像、用户 UID、注册时间等；
  • 第三方登录信息：在您授权前提下，从华为账号、微信等获取的 OpenID、UnionID、昵称、头像等；
  • 交友资料与内容：您填写的城市、性别、生日（用于展示年龄）、简介、兴趣标签、个人相册，以及发布的动态、评论、私信、打招呼与喜欢互动记录及上传的图片、视频；
  • 城市与同城展示：您主动填写的城市信息，用于同城内容展示与推荐；本应用不申请、不获取设备 GPS / 精确定位权限；
  • 设备与日志：设备型号、系统版本、应用版本、操作日志、崩溃信息、网络状态，以及设备标识信息（含 Android ID、OAID、IMEI、设备 MAC 地址等，以设备实际可读取范围为限）；为消息推送、支付风控与通道识别，应用及第三方 SDK（含个推消息推送 SDK / UniPush、支付宝支付 SDK、DCloud 引擎等）还会收集或使用 Wi‑Fi 网络信息（含 SSID、BSSID）以及软件安装列表（已安装应用列表）；
  • 交易信息：会员订单号、支付状态、权益使用情况；商城订单、商品与金额、支付与退款状态（支付密码由第三方支付机构处理，我们不收集完整支付密码）；
  • 收货与物流信息：您填写的收件人姓名、手机号、省市区与详细地址，以及为配送、查询物流所产生的运单号与物流轨迹相关信息；
  • 售后信息：您提交的售后类型、原因、说明、凭证图片，以及退货寄回时填写的快递公司与运单号等。

信息的使用目的（概览）

  • 注册登录、身份验证、密码找回与账号安全；
  • 展示交友资料，实现发现页推荐、打招呼、喜欢互动、访客记录、社区动态、私信与通知；
  • 会员权益发放（如打招呼额度、谁看过我、优先曝光等）、商城下单与履约、物流配送、售后与退款、客服处理；
  • 反欺诈、反垃圾、违规内容处置及履行法定义务；
  • 统计分析、产品优化（尽量采用去标识化方式）；
  • 消息推送到达率保障、网络环境识别与安全风控（含必要时使用 SSID、BSSID 等网络信息）。

以下按具体业务场景进一步说明：

1.1 账号注册与登录

为向您提供注册、登录与账号安全服务，我们需要收集您的手机号码、登录密码（加密存储）、验证码，以及您设置的昵称、头像、用户 UID。若您使用华为账号、微信等第三方登录，在您授权后我们可能获取 OpenID、UnionID、昵称、头像等。若不提供手机号等必要信息，您将无法完成注册登录。

1.2 个人资料与同城展示

为展示交友资料、发现页推荐与同城内容，我们收集您主动填写的城市、性别、生日、简介、兴趣标签及上传的个人相册等。本应用不申请、不获取设备 GPS / 精确定位权限；同城推荐依据您在资料中填写的城市。性别、生日等属于您可自主选择填写的资料；若不提供，可能影响部分匹配与展示效果，但不影响基本浏览。

1.3 内容发布与社交互动

为提供动态发布、评论、打招呼、私信、喜欢、关注及访客记录等功能，我们收集您主动发布的文字、图片、视频、评论与私信内容，以及互动行为（点赞、喜欢、关注、打招呼等）。访问他人主页时，我们可能记录访客信息并向会员用户展示「谁看过我」。若不提供相关内容，您仍可浏览公开信息，但无法完成发布与互动。

1.4 会员与支付交易

为开通会员与处理相关订单，我们收集订单号、套餐信息、支付状态、权益使用情况。支付过程中的银行卡号、支付密码等由微信支付、支付宝、华为支付等第三方处理，我们不收集完整支付密码或银行卡完整卡号。

1.5 商城购物、收货地址与物流

为向您提供商城商品浏览、下单、配送与订单管理服务，在您使用商城相关功能时，我们可能收集并使用以下信息：

  • 收货地址信息：收件人姓名、手机号码、所在省市区、详细地址及您设置的默认地址等。上述信息由您主动填写或选择；若不提供，您将无法完成需配送的商品下单。
  • 商城订单信息：商品名称与规格、数量、订单金额、优惠信息、订单状态、下单与支付时间等，用于履约、对账、售后与客服。
  • 支付信息：支付渠道、支付状态、商户订单号等必要交易信息；完整支付密码、银行卡号等由支付机构处理。
  • 物流信息：发货后产生的快递公司、运单号及查询所得的物流轨迹状态，用于展示配送进度、签收确认与售后时效判断。

您可在应用内「收货地址」中新增、修改、删除地址或设置默认地址。我们仅在实现配送、售后与依法留存订单所必需的范围内保存上述信息。

1.6 售后退款与凭证

当您申请仅退款、退货退款等售后服务时，我们可能收集：售后类型、申请原因、补充说明、您上传的凭证图片，以及退货寄回时填写的快递公司与运单号。上述信息用于审核售后、安排退货收件、办理退款与纠纷处理。凭证图片由您自愿上传；在部分售后类型下，为核实商品或物流情况，可能需要您提供说明或凭证，否则可能影响售后办理。

1.7 设备信息、日志与安全保障

为保障账号与服务安全、进行统计分析与消息推送、排查崩溃，在您同意本政策后，我们及所接入的第三方 SDK 会收集：设备型号、操作系统版本、应用版本、网络状态、操作日志、崩溃日志，以及设备标识信息（包括 Android ID、OAID、IMEI、设备 MAC 地址等，以设备与系统实际可读取范围为限）。为保障推送到达率、识别网络环境与安全风控，消息推送 SDK（含个推消息推送 SDK / UniPush）会收集或使用 Wi‑Fi 网络信息（含 SSID、BSSID）以及软件安装列表（已安装应用列表）。本应用基于 DCloud uni-app 开发，运行期间引擎及相关 SDK 会按需收集上述标识与网络信息，详情亦可参阅《DCloud App 引擎隐私政策》。

二、权限调用说明

在提供服务过程中，我们可能在您使用对应功能时申请以下设备权限。您可拒绝授权，仅对应功能不可用；也可在系统设置中随时关闭。

  • 相机权限：在您主动拍摄头像、个人相册、动态配图或售后凭证时申请，用于拍照上传。
  • 存储/相册（或照片与视频）权限：在您主动从相册选择图片或视频以上传头像、个人相册、发布动态或售后凭证时申请，用于读取您选定的文件。
  • 网络权限：用于连接服务器，加载内容、登录、支付、商城与消息同步。
  • 通知权限（如系统要求）：用于向您发送打招呼、喜欢、评论、系统公告等通知（可在系统设置或应用内通知开关中关闭）。

本应用不申请精确定位、通讯录、通话记录、短信、麦克风常开录音等权限。关于软件安装列表：本应用自身不以「获取您手机全部应用清单做画像」为目的申请权限；但为实现推送通道识别与支付安全风控，接入的第三方 SDK（如个推消息推送 SDK / UniPush、支付宝支付 SDK、DCloud 引擎）会在您同意本政策后按第 1.7 条所述目的、方式与范围读取软件安装列表，详情见本政策第 1.7 条与第 4.2 条。

三、我们如何使用 Cookie 及其他同类技术

本应用主要为原生 App，可能使用本地存储（如 SharedPreferences / 本地缓存）保存登录态、隐私同意状态、偏好设置等，以便您无需重复登录或重复确认。我们不会将上述技术用于本政策所述目的之外的用途。您可通过清除应用数据、退出登录等方式清除部分本地信息，但可能影响正常使用体验。
